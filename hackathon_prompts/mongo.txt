Modern applications require a database that can adapt as quickly as developers can build. As a general-purpose developer data platform, MongoDB Atlas lets you focus on building features, not managing data. It powers a vast range of applications, from simple web apps to complex, real-time AI solutions, by providing a single, unified developer experience for any data requirement.

Your challenge
Build an innovative application that solves a real-world problem, using MongoDB Atlas as its foundational backend data store.

Requirements
Your application must rely on a MongoDB Atlas database for its core functionality.
Use at least one of the MongoDB Atlas features below. The more of them you use, the more points you get.
MongoDB Atlas features
Atlas Search for text search
Atlas Vector Search
Hybrid Search
Automated Embedding
Atlas Stream Processing
Voyage AI by MongoDB models (some of these are already part of Automated Embedding)
Who it's for
Skill level: at least beginner level in any backend or full-stack programming language.
Languages: any of C, C++, C#, Go, Java, Kotlin, Node.js, PHP, Python, Ruby, Rust or Scala.
AI tools: use any you like.
